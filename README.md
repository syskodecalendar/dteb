# DTEB Website Preview

Open `index.html` to browse the multi-page site.

Pages: Home, About Us (with CEO message), Services, Portfolio, Insights, Contact. An internal-only browser enquiry dashboard is in `demo-admin.html`.

The supplied DTEB anniversary logo is used throughout. Architectural editorial photography loads from Unsplash (internet required); these are not documented photographs of the named DTEB projects. Project records and CEO-message summary are based on DTEB published materials.

The assistant is rule-based and the enquiry form uses browser localStorage. No server, email service or live AI provider is connected. The internal dashboard has no authentication; it must not be published for operational use.

For deployment as a static site, use the folder root as publish directory. Before production: obtain approval for all images/content, provide actual project photographs, add an authenticated backend and secure enquiry delivery, accessibility/performance QA, and bilingual content if needed.

## New detail pages

All service Learn more links lead to dedicated service pages, every portfolio card links to a project detail, and every Insights card links to an article. The header/footer design remains the same.
